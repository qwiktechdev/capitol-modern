# De Capitol Modern

A modern redesign of the De Capitol banking platform — same functionality, refreshed UI.

## Design

- **Typography:** Plus Jakarta Sans
- **Colors:** Navy brand palette with gold accents
- **Components:** Tailwind CSS utility classes + shared design tokens
- **Layout:** Sticky glass navbar, modern sidebar, gradient stat cards

## Run locally

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000)

## Build & deploy

```bash
npm run build
npm run deploy_production
```

## Project location

This is a copy of the original **De Capitol** project with visual-only changes. All routes, Firebase integration, and business logic are preserved.
